Wrapper classes in Java

Every primitive type in java has a corresponding wrapper class: Boolean, Byte, Short, Character, Integer, Long, Float,
Double.

Wrapper classes are objects that encapsulate primitive Java types. They are useful because generic classes only work
with objects and don't support primitives — making wrapper classes essential for the Java Collections framework and
other generic APIs.

-------------------------

Boxing & Unboxing:

	- Boxing — storing a primitive value into a wrapper class object.
	
	- Auto-boxing — Java handles boxing automatically when assigning a primitive to a wrapper type variable.
	
	- Unboxing — extracting the primitive value back from a wrapper object.
	
	- Auto-unboxing — Java handles this automatically on assignment.

Example:

// Auto-boxing — primitive to wrapper automatically
int primitiveInt = 42;
Integer wrappedInt = primitiveInt; // Java boxes it automatically

// Auto-unboxing — wrapper to primitive automatically
Integer wrappedValue = 100;
int primitiveValue = wrappedValue; // Java unboxes it automatically

-------------------------

Creating & Converting:

	- Simply assign like any regular variable — object initialization with new (e.g. new Integer(5)) has been
	deprecated since Java 9.
	
	- To convert back to a primitive, use methods like intValue(), doubleValue(), floatValue(), etc.

-------------------------

Utility Methods 
Wrapper classes also provide useful static methods and constants, here are a few examples:

	- Integer.parseInt("42") — parse a String to primitive.
	
	- Integer.MAX_VALUE / Integer.MIN_VALUE — useful constants.
	
	- Integer.toBinaryString(5) — type conversions.

-------------------------

Important Gotchas:

	- Unlike primitives, wrapper objects can be null — auto-unboxing a null wrapper throws a NullPointerException.

	Example:

	Integer wrapper = null;
	int primitive = wrapper; // throws NullPointerException at runtime!

	// Always null-check before unboxing
	if (wrapper != null) {
    	    int safe = wrapper;
	}

	-------------------------

	- Boxing/unboxing has a performance overhead — in performance-sensitive loops, prefer primitives directly.

	Example:

	// Slow — boxes/unboxes on every iteration
	Long sum = 0L;
	for (int i = 0; i < 1_000_000; i++) {
    	    sum += i;
	}

	// Fast — stays primitive the whole time
	long sum = 0L;
	for (int i = 0; i < 1_000_000; i++) {
    	    sum += i;
	}

	-------------------------

	- Integer caches values between -128 and 127, so == comparison may give unexpected results outside that range —
	always use .equals() to compare wrapper objects.

	Example:

	Integer a = 127;
	Integer b = 127;
	System.out.println(a == b);      // true  (cached range)

	Integer c = 128;
	Integer d = 128;
	System.out.println(c == d);      // false (outside cache!)
	System.out.println(c.equals(d)); // true  — always use this
